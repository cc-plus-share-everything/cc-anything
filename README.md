# cc+Anything

用 Claude Code 纯代码复刻爆款视频。每一期开源**动线图**（制作流程设计）和**提示词**，付费生成调用为 0，全部本地渲染。

抖音账号：cc+Anything

## 期数

| 期 | 复刻对象 | 技术 | 文档 |
|---|---|---|---|
| 01 | 《中华民族的救亡图存》3D 拼图地图（2:09） | Blender Python + PIL + ffmpeg | [01-jindaishi-puzzle-map](01-jindaishi-puzzle-map/) |

## 每期目录里有什么

- `README.md`：动线图 + 制作过程 + 踩过的坑
- `PROMPTS.md`：每个阶段可以直接复制的提示词
- `img/`：复刻版截图

## 不包含什么

- 渲染工程源码（Blender 场景脚本、贴图、时间表）不在本仓库。
- 原片的视频、音频、旁白文案不在本仓库。画面设计与文案属于原作者，每期文档里都写明出处。

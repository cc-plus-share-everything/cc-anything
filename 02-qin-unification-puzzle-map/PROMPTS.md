# 提示词

分两部分：这一期实际对 Claude Code 说过的话，以及整理好、可以直接复制去做别的历史题材的提示词。

## 一、实际说过的话

1. `今天做了一个视频，抖音发布失败了，不知道什么原因。得重新做一个，基于今天jindaishi这个作品和素材，做一个讲 秦始皇统一六国的，表现形式和当前的类似。也是竖屏，旁白，关键事件的配音。`
2. `整体很好，一气呵成。做个系列logo图吧`
3. `这个logo不太行，参考jindaishi 那个，这个是第一集`

从第 1 句到成片，中间没有再问问题。能这么短有两个原因：项目里有一份约束文件（见第 01 期的 PROMPTS.md），以及上一期的整套工程就在旁边可以读。

第 2、3 句是一次沟通偏差：「系列 logo 图」实际指的是系列封面。Claude Code 先画了一个四块拼图的方形标志，被否掉后才按上一期的封面版式重做。

## 二、换题材的提示词

前提：你已经有一期做完的拼图地图工程（做法见第 01 期）。把 `<…>` 换成自己的内容。

### 1. 一句话版本

```text
基于 <上一期的目录> 这个作品和素材，做一个讲 <新题材> 的，表现形式和它类似：
竖屏，有旁白，关键事件配音效。付费调用为 0，全部本地做。
```

### 2. 想控制得细一点，就分段给

**脚本**

```text
先只写脚本，不要写代码。
- 时间范围：<起> 到 <止>。
- 12–16 句旁白，每句只讲一件事，按时间顺序；正片总时长控制在 70 秒左右。
- 每条史实核对出处，数字只用有明确出处的；有争议的地方单独列出来告诉我。
- 另外写一句开头钩子（先给结果）和一句片尾。
- 标出 3–5 个关键事件，分别说明画面和声音打算怎么强调。
```

**地图**

```text
这个年代没有现成的边界数据。按下面的办法做拼图块：
1. 手绘一份示意疆域：每个势力一个经纬度多边形，沿主要山脉和河流画，标明是哪一年的形势。
2. 用现代地级市边界和它求交集，一个市跨两个势力就切开；太小的碎片并入同一个市里最大的那块。
3. 换一个以这片区域为中心的投影，并把比例放大到和上一期的场景差不多大，相机和灯光参数就不用改。
4. 底盘只画陆地和海，不画现代国界；周边写当时的称呼。
先出一张平面预览图给我看疆域和配色，再往下做。
```

**旁白先行**

```text
先生成旁白，再排时间表：
- 用 <参考音> 本地克隆，逐句生成；去首尾静音，句内停顿超过 0.3 秒的压到 0.3 秒，统一提速 <1.12> 倍。
- 把每句的实际时长写进一个文件。
- 时间表里每段的开始时间由这些时长累加得到；翻面、镜头、字幕、讲解卡都写成「某一段的百分之几处」，不要写死秒数。
```

**版式**

```text
竖屏 1080×1920。平台底部的文案会盖住画面下方约 28%，
所以字幕和讲解卡都放在上方 72% 以内，地图中心放在上半部。
先渲低清静帧，叠上后期，拼成联系表给你自己检查一遍，再渲全片。
```

**关键事件**

```text
这几个节点单独处理：
- <事件 A>：全屏压暗，居中大字 + 一张配图，铺底音乐停下，配 <声音>。
- <事件 B>：在地图上加 <2D 特效，例如蓝色水纹>，配 <声音>。
- <事件 C>：先翻过去，再翻回来，表示打下来又丢了。
- 结尾：全图翻成 <一张完整的图案>。
音效全部用代码合成，不用外部素材。
```

**配图**

```text
去维基共享找 <N> 张配图：<逐项列出要什么>。
- 只要公有领域、CC0、CC BY、CC BY-SA 的，授权从接口的元数据里读，不要猜。
- 每张下载后打开看一眼，确认内容对得上；对不上就换。
- 记一份来源表：文件名、链接、作者、授权、需要的署名文字；拿不准的地方单独标出来。
```

**收尾检查**

```text
成片后做完这几件再告诉我：
- 完整解码一遍；全片每隔几秒抽一帧拼成联系表，自己看版式有没有问题。
- 量响度和峰值。
- 用本地语音识别把旁白逐句转写，和脚本对照；拿不准的句子列出来让我听。
- 列出和史实有出入、做了简化的地方，我发布时写进简介。
```
